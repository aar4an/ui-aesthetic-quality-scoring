# UI Aesthetic Labeling Criteria

## 1. Definition of Good UI
A webpage is labeled **Good** when it shows a clean, well-organized layout with clear visual hierarchy. Spacing between elements is generous and consistent, contrast is strong enough for easy readability, and the overall composition guides the eye naturally from one section to the next. Colors are used purposefully rather than excessively, and there is no visual clutter competing for attention.

## 2. Definition of Average UI
A webpage is labeled **Average** when the design is functional and acceptable but lacks refinement. Layout and spacing are reasonable but not polished — sections may feel slightly inconsistent, some visual elements may be crowded, or hierarchy may be present but not strongly emphasized. The page is usable, just not visually strong.

## 3. Definition of Poor UI
A webpage is labeled **Poor** when the layout is cluttered, contrast is weak, and there is little to no visual hierarchy guiding the user. Elements may be crammed together, spacing is inconsistent or absent, and the overall impression is visually noisy or hard to navigate.

## 4. Labeling Criteria
Each screenshot was evaluated against the following factors :

| Factor | Good | Average | Poor |
|---|---|---|---|
| Simplicity | Minimal, focused | Some unnecessary elements | Overloaded |
| Spacing | Generous, consistent | Adequate | Cramped |
| Visual hierarchy | Strong, clear | Present but weak | Absent |
| Contrast | Strong | Moderate | Low |
| Color use | Purposeful, harmonious | Acceptable | Excessive / inconsistent |
| Alignment | Precise | Mostly aligned | Misaligned |
| Layout balance | Well balanced | Slightly uneven | Cluttered / unbalanced |

A score out of 10 was assigned alongside the label:
- **Good** → score 8
- **Average** → score 5
- **Poor** → score 2
